## 🎯 Methodology

My auditing approach focuses on:

1. **Understanding the protocol design deeply**
2. **Identifying trust assumptions and invariants**
3. **Testing edge cases (non-standard ERC20s, reentrancy, etc.)**
4. **Writing PoCs to validate real exploitability**
5. **Providing practical, developer-friendly fixes**
